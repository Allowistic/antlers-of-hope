# Antlers of Hope — Website Prototype

A high-fidelity static website prototype for **Antlers of Hope Bar & Grill** on Highway 190 in Porterville, California.

**Live Preview (once GitHub Pages is enabled):**  
https://allowistic.github.io/antlers-of-hope/

---

## Purpose

This is a ready-to-review prototype built for feedback from the Antlers of Hope team (Mike & Rhonda Harvey) and the HOPE Inc. community before going live.

The design captures:
- The warm, cinematic, Yellowstone-inspired spirit of a classic American roadhouse
- The authentic character of the **Mighty 190** (CA-190) and the foothills near Springville
- The heartfelt mission of **Helping One Person Everywhere Inc. (HOPE)** — neighbors helping neighbors facing medical hardship

---

## What's Included

- Fully responsive, beautiful single-page website
- Hero, story, bar & grill details, menu, live music/events, merch store, highway context, and HOPE mission sections
- 6 original embroidered-style merch patch designs + apparel mockups
- Working interactive elements (menu filtering, lightbox gallery, donation & merch modals)
- All imagery custom-generated to match the exact aesthetic (no generic stock)

**Tech:** Pure static HTML + Tailwind CSS (via CDN). Zero build step, zero backend.

---

## Local Preview (for reviewers)

```bash
# Clone the repo
git clone https://github.com/Allowistic/antlers-of-hope.git
cd antlers-of-hope

# Simple local server
python3 -m http.server 8080
# or: npx serve .

# Then open http://localhost:8080
```

On Windows you can also just double-click `index.html` (some features work best with a local server).
